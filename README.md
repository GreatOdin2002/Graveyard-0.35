# «Вечный покой» 6.0

Браузерная текстовая игра-симулятор смотрителя деревенского кладбища.
Мрачная атмосфера, дневной цикл, экономика, крафт, лес и деревня.
Чистый HTML/CSS/JS без фреймворков и сборщиков — проект живёт там, где лежит `index.html`.

## Запуск

Открыть `Graveyard/index.html` в браузере — либо любой статический сервер:

```
cd Graveyard && python3 -m http.server 8000
# http://localhost:8000
```

## Проверка

```
node tools/smoke.mjs   # ожидание: SMOKE: 22/22 OK
```

Работает из корня репозитория и из `Graveyard/` (резолвинг корня устойчив к расположению).
Клавиатура в харнессе — эмуляция keydown: реальные браузеры и мобильная вёрстка проверяются вручную.

## Структура

- `Graveyard/index.html`, `Graveyard/css/style.css` — разметка и палитра «старый дневник»;
- `Graveyard/js/core/` — состояние, сохранения (версия формата, миграции, восстановление повреждённого сейва), детерминированный rng;
- `Graveyard/js/data/` — игровые правила: 30 действий по единому контракту `{ok, toast?, sfx?, log?, fx?, silent?}`;
- `Graveyard/js/screens/`, `Graveyard/js/ui/` — экраны и интерфейс;
- `tools/smoke.mjs` — авто-смоук (22 чека, включая инвариант детерминизма и регресс на 60 игровых дней);
- `tools/patches_33.py`, `tools/patches_34.py`, `tools/patches_35.py` — патч-скрипты истории ревизий.

## Про патч-скрипты

Это история ревизий, а не текущие задачи: они уже применены в коде.
На свежем клоне `python3 tools/patches_35.py` выведет 9/9 `[skip]` — это признак правильно собранного кода, а не баг.
